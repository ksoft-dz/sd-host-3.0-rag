# intermediates — Pipeline Working Data

## Purpose

All intermediate outputs produced by Phases 1–2. These are the source of truth that Phase 3 merges into the final `metadata/metadata.json`. Every file here is reproducible by re-running the corresponding pipeline phase.

## Contents

### Phase 1 Outputs (deterministic)

| File | Producer | Description |
|------|----------|-------------|
| `discovery.json` | `analyze_pdf.py` | PDF structure: page count, TOC regions, page offset |
| `toc_sections.json` | `extract_toc.py` | Parsed section entries from TOC |
| `toc_tables.json` | `extract_toc.py` | Parsed table entries from TOC |
| `toc_figures.json` | `extract_toc.py` | Parsed figure entries from TOC |

### Phase 2 Outputs (LLM-generated)

| File/Dir | Producer | Description |
|----------|----------|-------------|
| `sections.json` | `extract_sections.py` | 146 text chunks with abstracts and keywords |
| `tables_page_map.json` | `extract_tables.py` | Table metadata (ID, title, page, CSV path) for 60 tables |
| `tables_csv/` | `extract_tables.py` | 60 CSV files — one per table (LLM-extracted from page images) |
| `tables_images/` | `extract_tables.py` | 93 rendered page images used for table extraction |
| `figures_page_map.json` | `extract_figures.py` | Figure metadata for 83 figures |
| `figures_plantuml/` | `extract_figures.py` | 83 PlantUML files — one per figure |
| `figures_images/` | `extract_figures.py` | 76 rendered page images used for figure extraction |
| `registers.json` | `extract_domain.py` | 34 registers with 114 fields (parsed from table CSVs) |
| `features.json` | `extract_domain.py` | 61 features + 9 HD sequences with LLM descriptions |
| `validation_report.json` | `validate.py` | Sanity check results (errors + warnings) |

## Key Notes

- **Do not edit manually** — these are machine-generated; re-run the pipeline instead
- **`--skip-existing`** flag skips items whose output files already exist here
- **Safe to delete** — any file can be regenerated by re-running the appropriate phase
- **Images are large** — `tables_images/` and `figures_images/` contain rendered PDF pages at 200+ DPI
